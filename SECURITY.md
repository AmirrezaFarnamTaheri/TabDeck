# Security policy

## Supported release

Security fixes target the latest published TabDeck v1 release line.

## Report a vulnerability

Use GitHub private vulnerability reporting for the repository when enabled. Include affected component, reproduction steps, impact, Android/browser versions, and any minimal proof-of-concept data needed to validate the issue.

Do not include real browsing history, bridge tokens, signing keys, or unrelated personal data. Do not open a public issue for an unpatched vulnerability.

## Scope

High-priority reports include bridge authentication or network-scope bypass, unsafe URL launch, backup/export injection, connector credential exposure, unauthorized Android target closure, signing/release compromise, migration data loss, and destructive-action recovery failures.

General feature requests, unsupported browser limitations, and issues requiring root or a compromised device are not normally security vulnerabilities.
